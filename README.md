# HH Goa 2026 — Builder ID

A fast, client-side Builder ID generator for HH Goa 2026.

## Features
- JPG / PNG / HEIC / WebP photo input
- Photo zoom and repositioning
- Name, role and stack
- Automatic Builder Title
- Unique Builder ID
- Live preview
- PNG download
- X share with `#FrameInGoa`
- Mobile responsive
- No login and no backend photo storage

## Run locally

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run build
```

## Deployment
Push the repository to GitHub and import it into Vercel as a Next.js project.
